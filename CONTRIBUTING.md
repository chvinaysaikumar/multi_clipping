# Contributing

- Run `python clipwatcher.py --selftest` before opening a pull request; CI runs it on Windows, macOS and Linux.
- Run `./watch.sh --doctor` first if something doesn't work, and paste its output in your issue.
- For a bug, include the command you ran and the last ~30 log lines (remove any API keys).
- Keep new options off by default unless they clearly make clips better for most streams.
